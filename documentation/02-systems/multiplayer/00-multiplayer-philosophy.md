# Multiplayer Philosophy

Multiplayer interaction is indirect and underhanded.

Key concepts:
- Limited number of allies
- Region investments (bribes, sabotage)
- Benefits for betrayal
- Shared world manipulation

Head-to-head multiplayer is not part of the current alpha launch.
