This guide covers warband systems, the unit roster, map nodes, promotions, and what happens at the end of a run.

Quick Start

  • Build a squad and place tougher units up front.
  • Equip abilities and remember that empty die slots resolve as `1`.
  • Advance through run nodes while managing attrition between fights.
  • Use rest nodes to fully recover before pushing deeper.

Battle Rules

Combat, Positioning, and Abilities

Squad Positioning

  • Combat happens on a fixed 3x3 grid for both sides.
  • Front-row and back-row positioning matter, so tougher units usually belong in front and ranged pressure usually belongs in back.
  • Placement affects who can pressure safely and who is left exposed on the field.

Ability Scheduling

  • Equipped abilities fire in loadout order using cumulative speed, not all at once.
  • Each ability instance can fire at most once per 20-tick round.
  • Reordering a loadout changes when actions happen, even if the unit keeps the same abilities.

Dice and Empty Slots

  • Dice are attached to ability slots, not to a shared unit-wide dice pool.
  • If you equip the same base ability multiple times, those copies reuse the same slot setup.
  • Any empty slot resolves as `1`, so incomplete setups still work but hit softer.

Status Snapshot

  • Status effects include Poison, Bolstered, Sleep, and Bleeding.
  • Status timing resolves server-side during dedicated status phases.
  • Dead units stop taking later actions in the same tick.

Academy

How Promotion Works

Requirements

  • Promotion always advances a unit by exactly one tier.
  • You combine three max-level units of the same current type and tier.
  • The primary unit keeps its identity, while the two secondary units are consumed.

Results

  • The promoted unit resets to level 1 in its new tier.
  • Previously earned abilities stay with the unit across promotions.
  • Tier 3 promotions still require the authored rare region item.

Choosing a Destination

  • You can continue along the unit's current chain or branch into another eligible path.
  • Promotion does not allow tier skipping.
  • Sideways options are limited by paths the unit has actually earned through earlier choices.

Why It Matters

Promotion is both a power jump and a long-term build decision, because your unit's combat catalog accumulates over the path it has traveled.

Expeditions

How Runs Work

During a Run

  • Unit HP persists between encounters, so attrition is part of the challenge.
  • Cooldowns and status effects clear after combat, but missing HP does not unless you rest.
  • Rest nodes are the primary way to fully recover before continuing.

If You Die

  • A combat or boss defeat immediately ends the run.
  • No retry is allowed inside that run.
  • Defeated units lose their current-level XP progress, but no unit loses a level.

If You Abandon

  • Abandoning a run uses the same resolution outcome as a failed run.
  • The energy spent to start the run is not refunded.
  • Abandon exists mainly to escape a doomed or stuck expedition.

After Any Run Ends

  • All units heal back to full after the run summary cleanup.
  • Rechargeable abilities recover and status effects are cleared.
  • Successful runs differ from failed or abandoned runs mainly in rewards and progression payout.
