# Progression Balance Targets

This document captures the intended campaign pacing for the current biome ladder:

- `The Farm`
- `Mountains`
- `Swamps`

It is a rebalance target, not a statement of current live balance.

## Core Principles

- Completing a run is not the only valid outcome.
- Abandoning a run should be treated as a normal extraction choice when the player has gained enough value.
- Partial runs must still deliver meaningful XP, resources, and forward momentum.
- Biomes should be balanced around expected `runs-to-clear`, not only around isolated fight difficulty.

## Desired Campaign Shape

### The Farm

Role:

- Onboarding biome
- First clear should be achievable immediately after unlock
- Teaches the core run loop: combat, loot, rest, boss, exit

Target pacing:

- Clearable on the first run for a normal player
- A second run may happen for cleanup, comfort, or extra resources, but should not be required

Expected player state:

- Small starting roster
- Low unlock depth
- Minimal system mastery required

Design implication:

- Farm enemies should teach mechanics, not hard-punish inefficiency
- Boss should feel memorable but beatable with starter-strength parties

### Mountains

Role:

- First true progression wall
- Introduces the expectation that partial runs are normal and valuable

Target pacing:

- Player should need `3 to 4` partial runs before unlocking the `6 unit` perk
- After unlocking `6 unit`, player should usually clear in `1 to 2` more runs

Expected player state:

- Some Tier 1 unit development
- Better understanding of run pacing and extraction decisions
- First meaningful roster-breadth expansion

Design implication:

- Early mountain progress must feel productive even when the player does not reach the boss
- Enemy composition should reward building a broader bench and stronger mid-run survivability

### Swamps

Role:

- First long-form progression biome
- Should demand deeper roster maturity and more system understanding

Target pacing:

- Player should usually need `4 to 6` partial runs before hitting the `9 unit` perk
- After that breakpoint, player should usually clear in `2 to 3` more runs
- Swamps should still be beatable without the `9 unit` perk by a strong `6-unit` roster with maxed mixed Tier 1 and Tier 2 units

Expected player state:

- Mature `6-unit` account progression
- Wider unit mix and better use of role coverage
- Some account-level unlock investment

Design implication:

- Swamps should reward deep roster quality first, extra roster size second
- The `9 unit` perk should feel strong and helpful, but not mandatory

## Abandoning Runs

Abandoning a run should be framed as:

- extracting with what you earned
- making a smart retreat
- regrouping after securing progress

It should not read as:

- wasted time
- a failed attempt with no value
- player error by default

Design requirements:

- partial run rewards must be visible and satisfying
- the UI and copy should communicate that extraction is a legitimate strategic choice
- biome difficulty should assume some players will intentionally leave before the boss

## Roster Breakpoints

### 3-Unit Phase

Expected use:

- Farm clear
- Early mountain probing

Goals:

- teach core combat
- make individual unit identity legible
- avoid forcing wide-roster assumptions too early

### 6-Unit Phase

Expected use:

- Main mountain clear phase
- Main swamp progression phase

Goals:

- unlock more role coverage
- reward investment into multiple units rather than one carry
- make formation and matchup choices more important

### 9-Unit Phase

Expected use:

- Late swamp acceleration
- Greater flexibility, not absolute requirement

Goals:

- smooth out bad matchup pressure
- create account-level payoff for long-term progression
- preserve the possibility of skilled 6-unit clears

## Biome Difficulty Standards

### Farm Standard

- Reachable boss
- Clearable boss
- Minimal grind expectation

### Mountain Standard

- Early partial progress is normal
- First clears should come after roster expansion
- Boss route should feel realistic after repeated improvement

### Swamp Standard

- Deep partial progression loop
- Significant pre-clear growth expected
- Broad but not infinite roster demand

## Rebalance Questions To Answer

- How much value should a player gain from a run abandoned after the first combat, second combat, or just before the boss?
- How much XP and resource gain is required to make `3 to 4` mountain partial runs feel good?
- How much stronger should a `6-unit` roster feel than a `3-unit` roster in practical run survival?
- How much stronger should `9-unit` progression feel in swamps without invalidating strong `6-unit` play?
- Which fights are meant to be blockers, and which are meant to be training fights?

## Immediate Rebalance Use

Use this document as the top-level pacing ruler when adjusting:

- enemy stats
- enemy action sequences
- enemy ability kits
- reward pacing
- unlock timing
- run extraction framing
